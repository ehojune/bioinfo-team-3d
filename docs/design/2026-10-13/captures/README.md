# 캡처 상태

현재 화면 2장과 시안 4종의 screenshot은 입력에 없었다. 기존 browser 접근은 자동 승인 검토에서 거절됐으며 headless Chrome은 권한 오류로 실패했다. 원본 demo 접근을 우회하지 않았다.

실제 PNG를 확보하지 못했으므로 가짜 캡처를 만들지 않았다. 갤러리 카드에는 원본 시안의 HTML preview를 넣었다. `../characters/*.png` 2개는 별도로 복사한 정적 proof sheet다.
