## 2026-10-16 — 필수 증거 칸의 누락을 드러내고 계속 (#657)

기존 “required evidence slots are never salvaged”는 한 칸의 출력 누락으로 독립 단계의 결과까지 CP2에서 막았습니다. 필수 칸을 없애지 않고, 코드가 누락 행을 써서 검토 대상으로 남깁니다.

| 결정 | 안전장치 |
|---|---|
| 필수 칸만 비었으면 같은 세션에 짧은 질문 1회 | 전체 JSON·분석 재실행 없음. 질문 전 기록으로 재시작 중 중복 방지 |
| 답변은 `slot_repair`, 무응답은 `omitted_by_output` | `unavailable`, 출처 없음. 발견 응답도 검증된 증거로 승격하지 않음 |
| row salvage 뒤 생긴 빈칸도 같은 경로 | 잘못된 행·그 행에만 기대던 주장은 기존처럼 거부. 계획 hash·step·나머지 계약은 엄격히 검사 |
| 독립 단계 결과는 CP2로 진행 | 실패·건너뜀·누락의 출처와 이유를 CP2·reviewer·보고서 한계에 보존 |
| 개발 보고 자동 기록 | 기존 dev log 또는 state의 JSONL에 요청 id·단계 id·오류 서명만 저장. 시설팀 경로 유지 |
