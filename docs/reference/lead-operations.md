## 현재 역할과 중단

2026-10-27 문서·인계 정비 기준이다. 이후 명시한 PI 지시가 우선한다.

| 담당 | 책임 |
|---|---|
| Claude 총괄 | 전체 구조·우선순위·기능 발굴·PI 소통·작업 배분. 중형 과제 담당 결정 |
| Codex 총괄 | Claude에게 받은 중대형 과제의 설계·분할·Codex worker 배정·통합 검증·완료 |
| Claude worker | 배정받은 중소형 과제의 구현·검증·PR·리뷰 대응·병합 |
| Codex worker | 배정받은 과제의 구현·진단·복구·PR·리뷰 대응·병합 |

- Codex 임시 전체 총괄은 **2026-10-28 21:00 KST 종료**. Claude 기동 여부로 연장하지 않는다. 역할 복귀·사용량 제한 해제·안내 예약은 개발 재개 승인이 아니다.
- 일반 개발·정기보고는 명시 재개 전 중단한다. 이번 문서·인계 정비를 새 연구·설치·실행·배포 또는 보류 PR의 수정/병합으로 넓히지 않는다. 과거 한도·종료한 시간창·보고 주기는 자동 갱신하지 않는다.
- 총괄은 계획·판단·PI 소통을 우선하고 worker는 소속 총괄에게 보고한다. 배정에 목적·Issue/PR·파일 소유·완료 증거·자율 복구·실제 한도/중단 조건을 명시한다. 승인 범위의 오타·인자·경로·진단 복구에 임의 1회 제한을 두지 않는다.
- 담당 worker가 최종 head CI·같은 head 실제 리뷰·알려진 P0/P1 수정검증·hold 조건을 확인하고 head guard로 병합한다. 리뷰/CI 대기를 도구에 맡겨도 결과 확인 책임은 담당자에게 남는다.
- Codex 리뷰 요청 시각·head·5분 뒤 확인을 기록한다. 무결과면 해당 PR만 Gemini로 전환한다. 접수·Running은 리뷰 완료가 아니다. Gemini 우선 시험은 현재 보류이며 지적은 근거·영향으로 판단한다.
- 방에는 담당자 mention·Issue/PR 링크·상태 변화·특이사항만 짧게 전달한다. 상세 근거는 Issue/PR에 두되 중단·승인·예산·기한 변경은 방 본문에도 명시한다. 같은 상태·수신 확인을 반복 보고하지 않는다.
- 인계는 완료·미완료·담당·head/hold·다음 권고와 미확인 사항을 한 번에 정리한다. README는 사용자 기능과 한계만 담고 내부 운영 이력을 쌓지 않는다.
