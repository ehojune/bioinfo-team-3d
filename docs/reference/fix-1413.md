# TSV 주석 검사 (#1413)

- 재현: 선행 `# method` 행을 한 칸 머리줄로 읽어 `table_shape`를 반환했다.
- TSV의 머리줄 앞에서 탭 없는 `#` 행만 건너뛴다. 탭이 있는 행은 머리줄로 보존한다. 한 열짜리 `#` 머리줄은 구별할 수 없다. 표 원본과 CSV는 바꾸지 않는다.
- mock 로컬 저장과 열 수 오류 거절을 시험했다. 실제 모델·HPC·PI 인스턴스 검증은 하지 않았다.

## 패키지 캐시 목록

- [관측](https://github.com/ehojune/bioinfo-team-3d/issues/1375#issuecomment-6810579072): `env/pkgs`의 압축 해제 패키지가 4 MiB 목록 상한을 넘겼다.
- `pkgs` 안의 일반 파일 `urls.txt`와 압축 해제 패키지의 일반 파일 `info/index.json`을 함께 확인할 때만 환경 폴더로 제외한다. 빈 캐시나 다른 이름의 캐시는 범위 밖이다.
- POSIX helper mock: 수정 전 캐시가 목록에 들어갔다. 수정 후 캐시 파일 20,001개는 제외되고, 일반 산출 20,001개는 계속 거절됐다. 유사한 일반 폴더도 보존했다.
- manual 15 한·영은 다른 작업 소유다. 두 파일에 같은 판정 조건을 반영해야 한다.

## 콘솔 종료 조사

- [관측](https://github.com/ehojune/bioinfo-team-3d/issues/1375#issuecomment-6811689075): `0xC000013A` 다섯 건 후 독립 콘솔로 재시작하자 재발하지 않았다. 실제 원인은 확정되지 않았다.
- `labhq/adapters/base.py`는 Windows 직원 CLI에 `CREATE_NEW_PROCESS_GROUP`을 지정한다. 이 플래그만으로 부모 콘솔을 분리하지 않는다. [Windows 프로세스 플래그](https://learn.microsoft.com/en-us/windows/win32/procthread/process-creation-flags), [콘솔 종료 신호](https://learn.microsoft.com/en-us/windows/console/handlerroutine) 참고.
- Windows mock에서 독립된 숨김 콘솔의 부모가 `CREATE_NEW_PROCESS_GROUP` 자식을 띄웠다. 둘의 콘솔 핸들이 같았고 콘솔을 닫자 둘 다 `0xC000013A`로 종료됐다. 실제 직원 프로세스나 PI 인스턴스는 실행하지 않았다.
- 당시 콘솔 연결 상태와 실제 장애 원인은 미확인이다. 최소 조사 범위는 `labhq/adapters/base.py`의 Windows spawn 분리와 기존 종료·취소 동작의 회귀 시험이다. 제품 변경은 별도 배정이 필요하다.
