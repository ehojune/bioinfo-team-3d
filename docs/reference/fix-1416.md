- 공개 시험에는 합성 경로만 사용했습니다. 비공개 내용·식별자·경로는 싣지 않습니다.
- 복사 전 run hash를 확인하고 변환 후 사본 hash를 기록합니다. JSON은 구조를 보존하며 가림 뒤 key 충돌이나 고정 checkpoint 변경은 거절합니다.
- 최초 임시 입력 시험에서 broker mock 누락으로 로컬 broker가 401을 반환했습니다. mock 추가 뒤 재현했으며 외부 제출은 없었습니다.
- 최초 test 편집 전 gate check는 상위 lane에서 실행해 거절됐으나 편집을 진행했습니다. 등록 checkout에서 같은 두 파일의 check 성공을 확인한 뒤 후속 편집을 진행했습니다.
- r2 status를 기록했습니다. 한 글자 가림은 기존 규칙을 따릅니다. 생성 기록·입력 목록·helper의 식별자와 schema는 보존하며 claims의 서술 내용은 가립니다. root checkpoint는 가릴 payload가 있으면 거절하고 동명 단계 산출은 가립니다.
- 실제 CP4·rerun receipt의 bundle 검증과 입력 연결 helper 실행을 합성 fixture로 확인했습니다. claim 근거 참조·provenance·README 명령·실제 산출의 그림 링크도 유지합니다.
- 가림은 [명시된 text 확장자·등록된 설정 이름](../../labhq/request_bundle.py)의 사본만 처리합니다. `condarc`·`.out`·`.err`는 포함하며 미등록 형식은 bytes를 보존합니다.
- 형식 header/footer는 짧은 일반 문자열과 구분합니다. 일반 텍스트·경로 변환은 순차 처리합니다.
- JSON 16 MiB, 한 줄 1M 문자, 남은 경로 1만 개·16M 문자 상한은 명시 오류로 거절합니다. 텍스트의 UTF-8 오류·NUL도 공개 묶음을 거절합니다.
- `.sh`·`.bash` script는 시스템 실행 경로·기본 device만 보존합니다. 구조화된 식별자 값에도 절대경로 가림을 적용하며 UNC·local URI 우회를 막습니다. URI는 HTTP(S)만 유지하고 나머지는 가립니다.
