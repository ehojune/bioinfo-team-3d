조회용 검증 기록입니다. [Issue #1416](https://github.com/ehojune/bioinfo-team-3d/issues/1416), [범위 축소 결정](https://github.com/ehojune/bioinfo-team-3d/issues/1416#issuecomment-6823083984).

| 확인 | 결과 |
|---|---|
| 가리는 것 | 사이트 프로필 `remote_workdir`로 시작하는 경로를 끝까지 `<remote-path>`로 치환 |
| 가리지 않는 것 | 다른 절대경로·URI·공백 뒤 경로, 경로 밖의 host·사용자·queue 낱말, 보고서·README·HTML·이진 파일 |
| 관련 시험 | request_bundle·step_inputs·encoding 4개 파일 187 passed, 2 skipped. 묶음·제출 관련 28개 파일 1217 passed, 37 skipped |
| 비공개 사본 | 저장 기준선 public 실패 파일 6→0, offline bundle 검증 PASS, 변환 5개 파일, 정리본 문서 3개는 그대로 |
| 원본 보존 | 기준선 전체 파일의 전후 SHA-256 동일 |
| 검증 경계 | 저장 judge의 public 함수와 bundle validator만 실행. PI CLI verify·연구 재실행·HPC 접속은 하지 않음 |

- 공개 시험은 합성 경로만 씁니다. 비공개 내용·식별자·경로는 싣지 않습니다.
- 기준선의 public 실패 6건은 모두 설정된 원격 작업 폴더 경로였습니다. 그래서 그 경로만 치환해도 0건이 됩니다.
- PR #1417은 리뷰마다 경로 모양 규칙을 더해 `request_bundle.py`가 +430줄이 됐고, 보고서의 닫는 태그를 경로로 잘못 가렸습니다. 이 PR은 그 PR의 첫 커밋(a346ef05)에서 출발해 치환 대상을 설정 값으로 좁혔습니다. `.tmp/` 입력 거절과 그 시험은 그대로 가져왔습니다.
