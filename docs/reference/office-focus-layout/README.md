# 사무실 배치 검증

화면 변경 근거를 찾을 때만 읽는 기록입니다. 모든 화면은 가상 요청이 진행 중인 내장 데모이며 실제 연구 데이터는 없습니다.

|---|---|---|
| 1440×900 | [전](before-desktop.png) | [후](after-desktop.png) |
| 390×844 | [전](before-phone.png) | [후](after-phone.png) |

- 기준: `568c29e`; 테스트 서버와 Chrome은 OS가 고른 빈 포트를 사용했습니다.
- `tests/web_office_focus_layout.cjs`: 필수 회귀 5개와 버전 이관·폰·instance 격리·완료 접기를 확인합니다.
- 버튼 경로는 연결돼 있었지만 작업판 맨 위로 이동했습니다. 실패 이유와 남은 결과는 긴 단계 목록 아래에 있어 화면 밖에 남았습니다. 이제 결과 영역으로 스크롤하고 키보드 초점을 옮깁니다.
- `tests/visual/demo-layout.baseline.json`: 데스크톱·폰, 네 데모 단계, 네 탭/직원 보기 조합 32개를 기록합니다.
