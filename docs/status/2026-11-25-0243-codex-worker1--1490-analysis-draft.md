# 2026-11-25 codex-worker1 · #1490 r9 · 분석 세션의 보고서 초안

Refs #1490

## 결론

간소화 옵션을 저장한 무분기 연구에서는 분석 세션이 보고서 초안을 작성합니다. CSO는 runner가 수집한 SHA-256과 원본을 대조하고, 근거 승인과 연구 리뷰를 거친 초안을 검사해 보고서를 조립합니다.

## 바뀐 것

- 분석 단계에 Markdown 초안 수집 경로를 전달합니다. 경로는 승인된 계획 해시와 연구 차수에 묶습니다. 새 차수가 승인되면 초안 작성 단계가 다시 실행됩니다.
- 분석 세션에서 다른 모든 단계의 결과를 이미 읽을 수 있으면 그 자리에서 씁니다. 후속 검증이나 병렬 단계가 있으면 결과가 모두 모인 뒤 같은 분석 세션을 재개합니다. 세션을 이어갈 수 없으면 보고서 생성이 실패합니다.
- 후속 초안은 리뷰 전에 경로와 SHA-256을 저장합니다. 재시작 뒤에는 같은 초안을 다시 대조합니다. 보고서의 결과 링크는 요청 묶음의 경로를 씁니다.
- 초안 누락·변조, claim 검사 실패, 결과표 불일치·읽기 실패, 보고서 계약 실패는 성공으로 처리하지 않습니다. 리뷰 순서와 기존 요청의 계획 해시는 그대로입니다.
- r9에서는 runner와 CSO가 UTF-8 초안과 결과표를 수집 SHA-256으로 대조합니다. Gateway에 전송 기능이 연결된 요청에서만 내부 결과에 파일을 싣습니다. 08장 한영판에 graphical abstract 작성 단계를 반영했습니다.
