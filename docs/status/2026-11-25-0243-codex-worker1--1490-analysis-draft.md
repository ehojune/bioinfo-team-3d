# 2026-11-25 codex-worker1 · #1490 r8 · 분석 세션의 보고서 초안

Refs #1490

## 결론

간소화 옵션을 저장한 무분기 연구에서는 분석 세션이 보고서 초안을 작성합니다. CSO는 runner가 수집한 SHA-256과 원본을 대조하고, 근거 승인과 연구 리뷰를 거친 초안을 검사해 보고서를 조립합니다.

## 바뀐 것

- 분석 단계에 Markdown 초안 수집 경로를 전달합니다. 경로는 승인된 계획 해시와 연구 차수에 묶습니다. 새 차수가 승인되면 초안 작성 단계가 다시 실행됩니다.
- 초안 누락·변조, claim 검사 실패, 결과표 불일치·읽기 실패, 보고서 계약 실패는 성공으로 처리하지 않습니다. 리뷰 순서와 기존 요청의 계획 해시는 그대로입니다.

## 확인

- 최종 코드에서 초안·재개·계획 해시 시험 25개가 통과했습니다. 실제 연구 요청과 별도 호스트의 runner는 미검증입니다. Gateway에서 수집 파일을 읽지 못하면 보고서 생성이 실패합니다.
- 제품 코드 순증 109줄입니다. 핵심 세 파일의 순증은 `cso.py` +32, `server.py` 0, `daemon.py` 0입니다. #1488 뒤 누계는 +44/82줄입니다.
