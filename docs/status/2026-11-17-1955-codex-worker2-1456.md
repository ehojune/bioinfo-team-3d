# #1456 — 작업 폴더의 개인 경로 오탐 설명 수리

## 한 일
- 자기 task·staged inputs가 상위 작업 root에 일치해도 개인 파일 접근으로 단정하지 않는다. 문법을 증명하지 못한 Bash 명령은 계속 개별 승인을 받는다.
- 닫힌 개인 경로와 registry 근거를 보존하고, 읽기 범위 미확인 카드의 사유를 고쳤다. 삭제·통제 자료의 별도 위험 표시는 유지한다.
- 세 제품 파일과 두 회귀 파일을 수정했다. [진단·제한](../reference/private-path-false-positive-1456.md)에 근거를 모았다.
- 한·영 safety 안내를 추가했다. P1 리뷰에 따라 private root의 열린 하위 폴더만 예외로 두고 settings·history·다른 task의 경고 근거를 보존했다.
- 후속 P1 수리: 해석 상한 뒤에도 명시한 개인 경로의 근거를 남기고 상대경로를 명령 순서에 맞춰 해석한다. pipeline의 `cd`는 다음 명령의 폴더를 바꾸지 않는다.
- `||` guard 뒤의 성공한 폴더 이동과 기존 위치 builtin·`builtin cd`도 이후 경로 판정에 남긴다.
- 그룹 내부 상태와 subshell 바깥 상태를 구별하고 `popd`·`cd -`의 복원을 반영한다.
- command substitution의 폴더 변경도 바깥으로 넘기지 않으며 pushd·popd의 `-n`은 폴더를 바꾸지 않는다.
- process substitution 경계와 indexed popd의 선택 위치도 반영한다.
- indexed pushd는 stack 회전으로 판정하고 함수 본문은 선언 시 실행하지 않으며 직접 호출 시에만 반영한다.
- `--` 뒤 폴더명과 reserved word 뒤 선언·함수 return을 구별하고 재귀 확장량을 제한한다.
