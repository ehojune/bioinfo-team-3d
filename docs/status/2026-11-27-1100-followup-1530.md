# #1530 부분 보고서 마감

Refs #1530

## 변경

- 예산 증액 거절·예산 상한·턴 소진으로 요청이 끝나면 완료한 단계의 수집 산출물로 부분 보고서를 저장합니다. 실패 상태와 종료 사유, 산출 경로·기록된 SHA-256, 누락을 남깁니다.
- 마감에는 모델 호출이 없습니다. 이미 작성한 연구 보고서와 단독 답변은 보존하고, 재시작이나 동시 마감에서 같은 종료를 다시 기록하지 않습니다.
- 리뷰 P2를 반영했습니다. 결과 승인 전후의 compact 초안 작성에서 한도 오류를 보존합니다. [리뷰](https://github.com/ehojune/bioinfo-team-3d/pull/1534#discussion_r4715082518)

## 검증

- Windows 관련 pytest 638건 통과. 합성 요청의 세 가지 종료 경로, 리뷰·보고서 작성·compact 초안의 턴 및 비용 상한, 중복 마감, solo 답변 보존을 확인했습니다. 공개 검사 통과.
- 제품 코드 순증 171줄(`cso.py` 52줄, 보조 모듈 119줄)로 상한까지 129줄 남습니다. 커밋 6개입니다.
- 초기 Linux CI의 solo 회귀를 수정했습니다. Windows와 Linux CI에서 새 시험의 Windows inventory 등록이 남았습니다. `config/ci/windows-boundary-v1.json`은 r1 수정 범위 밖입니다. [초기 CI](https://github.com/ehojune/bioinfo-team-3d/actions/runs/45928369827)
