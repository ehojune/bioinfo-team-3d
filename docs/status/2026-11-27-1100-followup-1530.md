# #1530 부분 보고서 마감

Refs #1530

## 변경

- 예산 증액 거절·예산 상한·턴 소진으로 요청이 끝나면 완료한 단계의 수집 산출물로 부분 보고서를 저장합니다. 실패 상태와 종료 사유, 산출 경로·기록된 SHA-256, 누락을 남깁니다.
- 마감에는 모델 호출이 없습니다. 이미 작성한 보고서는 보존하고, 재시작이나 동시 마감에서 같은 종료를 다시 기록하지 않습니다.

## 검증

- Windows 관련 pytest 614건 통과. 합성 요청 세 가지 종료 경로, 리뷰·보고서 작성 중 턴 소진, 중복 마감을 확인했습니다. 공개 검사 통과.
- 제품 코드 순증 169줄(`cso.py` 50줄, 보조 모듈 119줄)로 상한까지 131줄 남습니다. 커밋 2개입니다.
