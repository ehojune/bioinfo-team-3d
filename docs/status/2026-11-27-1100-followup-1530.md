# #1530 부분 보고서 마감

Refs #1530

## 변경

- 예산 증액 거절·예산 상한·턴 소진으로 요청이 끝나면 완료한 단계의 수집 산출물로 부분 보고서를 저장합니다. 실패 상태와 종료 사유, 산출 경로·기록된 SHA-256, 누락을 남깁니다.
- 마감에는 모델 호출이 없습니다. 이미 작성한 연구 보고서와 단독 답변은 보존하고, 재시작이나 동시 마감에서 같은 종료를 다시 기록하지 않습니다.
- compact 초안과 리뷰 후 재계획에서 한도 오류를 보존합니다. 팀 보고서와 direct 답변이 완성된 뒤 예산 증액이 거절되면 결과와 거절 사유를 함께 남깁니다. [초안](https://github.com/ehojune/bioinfo-team-3d/pull/1534#discussion_r4715082518) · [재계획](https://github.com/ehojune/bioinfo-team-3d/pull/1534#discussion_r4715156749) · [팀 보고서](https://github.com/ehojune/bioinfo-team-3d/pull/1534#discussion_r4715197068) · [direct](https://github.com/ehojune/bioinfo-team-3d/pull/1534#discussion_r4715284415)

## 검증

- r3에서 `tests/test_partial_closeout_1530.py`를 Windows inventory와 필수 실행 목록에 등록했습니다. 프로필 검증과 직전 CI 실패를 재확인한 pytest 7건이 Windows에서 통과했습니다. [직전 CI](https://github.com/ehojune/bioinfo-team-3d/actions/runs/45930329966)
- direct 회귀 테스트는 사후 예산 카드가 거절되면 답변을 보존하고 요청 기록과 `request.completed`에 거절 사유를 전달하는지 확인합니다.
- 팀·direct 수정과 Windows CI 등록을 한 커밋에 담고 패치노트 행을 추가했습니다. 제품 코드 순증 171줄(`cso.py` 52줄, 보조 모듈 119줄)이고 커밋은 10개입니다.
