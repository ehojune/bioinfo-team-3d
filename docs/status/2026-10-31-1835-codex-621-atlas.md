- GRCh38 SNV 10개, scorer·ontology·gene 필터, raw/quantile·gene/track metadata, 출처·사용 조건·일 단위 cache를 제공합니다. SDK 0.10.0, 자동 inference 전환 없음.
- runner만 API 키를 보관합니다. 직원 CLI/MCP 환경에서 키와 별칭을 빼고 고정 `/annot/atlas` 조회만 허용합니다. 키를 복원하는 launch override와 literal key의 직원 설정 복사를 실행 전에 거부합니다.
- task token 소유권·공개 조회 상한을 runner에서 확인합니다. 요청 16 KiB·동시 1건·기존 SDK/step deadline을 지키고 disconnect·성공·오류·취소 때 조회와 grant를 정리합니다.
- 비서실장의 Atlas 도구를 차단합니다. doctor는 Atlas 사용 직원의 실제 engine·force_engine 환경을 검사하고 일부 키 누락을 경고합니다. 빈 값·변수 확장·역할 제한 회귀를 포함합니다.
