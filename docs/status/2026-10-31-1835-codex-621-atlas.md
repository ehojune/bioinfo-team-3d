# #621 Atlas 조회와 runner credential 경계

- GRCh38 SNV 10개, scorer·ontology·gene 필터, raw/quantile·gene/track metadata, 출처·사용 조건·일 단위 cache를 제공합니다. SDK 0.10.0, 자동 inference 전환 없음.
- API 키는 runner backend에서 사용합니다. 다른 engine의 키 별칭이 직원 환경에 남는 P1은 가짜 키로 재현했으며 미해결입니다. `labhq/adapters/base.py` 소유권 추가가 필요합니다.
- task token 소유권·공개 조회 상한을 runner에서 확인합니다. 요청 16 KiB·동시 1건·기존 SDK/step deadline을 지키고 disconnect·성공·오류·취소 때 조회와 grant를 정리합니다.
- exact/wildcard Atlas deny를 availability와 broker grant 발급에 함께 적용해 직접 HTTP 우회도 막습니다. 다른 도구의 deny는 Atlas 허용을 유지합니다. doctor는 실제 직원 engine·force_engine의 키 누락을 검사합니다.
- 검증: deny 수정 전 **5 failed, 3 passed** → Atlas·literature·doctor·adapter·runner-env **306 passed, 12 skipped**. MCP 자식·직접 shell·SDK fixture 회귀 포함. 명령·최종 CI·리뷰는 [PR #1186](https://github.com/ehojune/bioinfo-team-3d/pull/1186)에 기록합니다.
- **UNVERIFIED:** 설치 Codex sandbox shell은 격리 HOME의 PowerShell·cmd 시험에서 각각 30초 timeout. 직접 shell 회귀를 실제 Codex 실행 PASS로 대신하지 않습니다. 실제 Atlas 조회도 키 접근 확인 전 미검증입니다.
- hold·미병합 유지. manual·CI inventory는 다른 담당자 소유이며 #621을 닫지 않습니다.
