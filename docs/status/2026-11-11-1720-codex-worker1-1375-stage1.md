# #1375 bench 표식과 receipt 정리

## 결론
bench 결과 표식의 분리·재결합과 receipt 상태 계산을 각각 한곳으로 모았다. 실제 연구 기준선 비교가 남아 PR은 hold다.

## 바뀐 것
- 표식이 하나이고 끝에 있을 때만 이동하며, 기존 부록·경고·리뷰 처리는 유지한다.
- 동기·비동기 receipt API는 같은 계산을 쓰고 각각 기존 저장 방식을 유지한다. 저장 뒤에 대기 대상을 계산한다.
- 물리 줄 수: CSO 9,067→9,047, recruit planning 425→402, 새 bench 모듈 18줄. 제품 순감소 25줄; CSO 추가 연결 코드 12줄(교체 포함).

## 실행한 것
- 수정 전후 bench·receipt 관련 시험 각 80건 통과.
- 수정 후 연구 보고·이어가기 시험 72건 통과. 로컬 회귀이며 HPC 기준선 비교가 아니다.

## 미해결
- 기존 실행의 완료 산출·hash·방향·receipt·실행 코드 SHA 확인과 변경 전후 실제 기준선 비교가 필요하다. CI 시간은 실행 완료 후 확인한다.
