# #1447 — HPC 산출의 PC 미수신 표시

## 결론
선언한 산출이 원격에 있으나 PC에서 확인되지 않으면 단계 결과와 알림에 경로·크기·이유를 표시한다. 검증된 원격 산출의 단계 성공과 후속 HPC 전달은 유지한다.

## 바뀐 것
- 기존 fetch manifest의 생략 사유와 수신 hash를 사용한다. 사이트별 상한 설정과 기존 기본값은 바꾸지 않는다.
- 재시작 후 저장된 생략 기록을 쓰고, 후속 잡이 받은 산출은 이전 누락으로 표시하지 않는다. 한·영 매뉴얼에 사용법을 적었다.

## 실행한 것
- 배포 venv: HPC remote data·site profile·transfer 시험 234 passed, 33 skipped. Windows에서 건너뛴 항목은 Linux CI에서 확인한다.
- 후속 잡의 수신 표시 보완 뒤 remote data 시험 47 passed, 21 skipped.
- 실제 HPC 접속·배포·연구 실행은 하지 않았다.

## 미해결
- 실제 스케줄러와 사이트 전송은 미검증이다. PC 단계의 원격 산출 소비는 별도 범위다.
