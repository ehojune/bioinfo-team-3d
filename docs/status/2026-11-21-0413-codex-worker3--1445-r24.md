# #1445 — 요청별 자동 승인 목록

## 결론

2.5D 작업판과 결정 탭의 검토 카드에서 **자동 승인 N건**을 펼치면 해당 요청의 명령, 직원, 단계, 부류가 나옵니다. 오래된 기록에 빠진 항목은 **기록 없음**으로 표시합니다.

## 바뀐 것

- 인증된 API에서 확정된 자동 승인 결정을 최근 순서로 반환합니다. 건수와 같은 기준을 쓰며 목록은 펼칠 때 불러옵니다.
- 한영 매뉴얼에 펼치기 동작을 넣고, 요청별 조회와 SQLite 재개방을 검증하는 테스트를 Windows CI 목록에 등록했습니다.

## 확인

- r25에서 Windows API·CI 정책 테스트 206건과 검토 카드 Node 테스트 10건이 통과했습니다. Windows CI 목록 검증도 통과했습니다.
- 이전 구현에서 모의 Gateway를 붙인 390px Chrome으로 두 화면의 펼치기, 요청 전환, 명령의 평문 표시를 확인했습니다.
- 배포와 실제 PI 요청은 미검증입니다. 최종 CI와 리뷰는 [PR #1469](https://github.com/ehojune/bioinfo-team-3d/pull/1469)에 기록합니다.
